iOS app

Sync Apple Health to your server from the app, a widget or Siri.

FreeReps is an iOS companion app that syncs Apple HealthKit data to a FreeReps server via HTTP. Your health data flows from HealthKit on your phone to your self-hosted server — no cloud services, no third parties.

Requires iOS 27 and a running FreeReps server

Shortcuts action

“Sync Health Data” for Shortcuts automations, Siri and the Action button.

Widget

Shows when the last sync finished and whether it succeeded; tapping it opens the app and starts a sync.

Full sync with resumable backfill

The first run backfills the configured range; later runs resend the 7 days before the previous run.

Server decides what it accepts

A fixed set of HealthKit types. Per user, the server picks which metrics it takes, and the app skips the rest before reading HealthKit.

Features

Five sources in. One database. Dashboard and MCP out.

Sources

Apple Health

The FreeReps iOS app sends only what changed since the last sync — heart rate, HRV, sleep, activity, workouts with GPS and more. Health Auto Export works as well.

Oura Ring Integration

Built-in Oura API v2 sync pulls readiness, sleep & activity scores, HR, HRV, SpO2, stress, workouts. Automatic dedup when both sources overlap.

Withings Integration

Weight, body composition and blood pressure read straight from the Withings API, ahead of the copy that arrives through Apple Health.

Strength Training

Hevy sessions and Alpha Progression exports become volume per muscle group, tonnage and estimated 1RM — correlatable against sleep and HRV.

Analysis

Correlation Explorer

Discover relationships between any two health metrics. See Pearson correlations with interactive scatter plots.

MCP for AI

Query your health data from Claude or any MCP-compatible assistant. 20 tools and 3 resources over stdio and Streamable HTTP.

Operations

Self-Hosted

Run on your own hardware. Docker Compose gets you running in minutes. Your data never leaves your network.

Tailscale Auth

Zero-config TLS and identity-based access via Tailscale. No passwords, no exposed ports.

Open Source

MIT licensed. Go backend, React frontend. Single binary with embedded web UI.
